\subsection{Corpus Curation, Evaluation Partitions, and Deduplication}
\label{subsec:dataset}

To ensure reproducible empirical evaluation without data leakage, we establish a unified corpus of $2,664$ Vietnamese telecommunications messages ($1,918$ benign ham, $746$ verified scam), combining the public benchmark \texttt{uitnlp/vietnamese-sms-phishing} ($2,629$ messages) with $35$ high-impact national phishing lures targeting Vietnamese citizens during 2023--2024 (e.g., impersonations of VNeID, VssID, and banking portals). Table~\ref{tab:dataset_sources} details the partition breakdown.

\textbf{Label Ontology and Operational Scope:} Messages are classified into three operational categories: \textbf{SCAM-RISK} (fraudulent intent, phishing URLs, extortion), \textbf{LOW-RISK} (benign transactional/personal messages), and \textbf{UNKNOWN} (ambiguous context requiring human discretion).

\textbf{Dataset Hygiene and Deduplication:} Unicode normalization (NFC) and whitespace sanitization were applied. Partition auditing confirmed zero exact or near-duplicate overlap between the Training Set ($N=1,865$, $522$ scam / $1,343$ ham), Stratified Validation Set ($N=532$, $149$ scam / $383$ ham), and the isolated Frozen Holdout Test Set ($N=267$, $75$ scam / $192$ ham). The Hard Forensic Challenge Suite ($N=117$, $98$ scam / $19$ ham) assesses edge cases with \textbf{99 / 117 ($84.6\%$)} template overlap against training data, containing 10 overlapping text strings and 99 training-derived templates evaluated as an exploratory development benchmark rather than a fully disjoint test set. As observed in \texttt{canhbao.khonggianmang.vn}, sample \texttt{BANK\_15}, threat actors mimic legitimate notices; zero benign samples are synthetic, and authentic customer service and promotional notifications outside the corpus were curated to stress-test false alarm rejection.

\subsection{Cost-Sensitive Loss Formulation ($\mathcal{L}_{\text{WBCE}}$) and Edge Quantization}
\label{subsec:wbce_quant}

To penalize missed fraud, Tier 1 optimizes transformer encoders using Cost-Sensitive Weighted Binary Cross-Entropy loss ($\mathcal{L}_{\text{WBCE}}$):
\begin{equation}
\label{eq:wbce}
\mathcal{L}_{\text{WBCE}} = -\frac{1}{N} \sum_{i=1}^{N} \left[ \alpha \cdot y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]
\end{equation}
where $y_i \in \{0, 1\}$, $\hat{y}_i = \sigma(z_i)$, and $\alpha = 5.0$ scales the gradient for false negatives $5\times$. Models are trained with AdamW ($\text{lr} = 2 \times 10^{-5}$, weight decay $0.01$, batch size $32$, $5$ epochs).

The fine-tuned ViSoBERT-base ($97.57\text{M}$ parameters) is exported to ONNX and quantized to INT8 via dynamic range quantization. The quantized artifact compresses disk footprint from $390.54\text{ MB}$ (FP32) to $98.42\text{ MB}$ ($93.86\text{ MiB}$, $74.8\%$ reduction). On consumer CPU (Intel i7-11800H, 4 threads, single-sample batch), median per-message latency is $70.7\text{ ms}$ (P95: $80.5\text{ ms}$).

\subsection{Two-Tier Routing and Deliberative Forensic Council}
\label{subsec:routing_council}

Incoming payload $x$ is evaluated by Tier 1. Confidence $C_{\text{T1}}(x) = \max(\hat{y}, 1 - \hat{y})$ determines execution flow against routing threshold $\tau \in [0.50, 1.0]$:
\begin{equation}
\label{eq:routing}
\text{Route}(x) = \begin{cases}
\text{Tier 1 (Local Edge Fast-Path)}, & \text{if } C_{\text{T1}}(x) \ge \tau \\
\text{Tier 2 (Forensic Council Escalation)}, & \text{if } C_{\text{T1}}(x) < \tau
\end{cases}
\end{equation}
At operating threshold $\tau = 0.90$, $96.6\%$ of messages are resolved on-device, incurring cloud escalation on only $3.4\%$ of ambiguous boundary cases.

Escalated payloads are evaluated by the Tier 2 Forensic Council. While a Reference 5-Agent Council Specification (Arm 1) was tested ($585$ API calls), production deploys a consolidated 3-agent council ($351$ calls, $40.0\%$ reduction):
\begin{itemize}
    \item \textbf{Seat A (Cyber-Financial Security Analyst, $w_A = 0.35$):} Identifies phishing URLs, fake subdomains, and unauthorized financial demands.
    \item \textbf{Seat B (Psycholinguistic \& Urgency Profiler, $w_B = 0.35$):} Detects coercive psychological triggers, teencode obfuscation, and threats.
    \item \textbf{Seat C (Public Defender \& Anti-Alarm Fatigue Advocate, $w_C = 0.30$):} Validates authentic institutional notification protocols and banking OTP syntax.
\end{itemize}

Specialist estimates $P_j$ are synthesized via:
\begin{equation}
\label{eq:council_aggregation}
P_{\text{council}} = \sum_{j \in \{A, B, C\}} w_j P_j - \delta_{\text{defender}} \cdot \mathbb{I}(\text{Seat C} = \text{BENIGN})
\end{equation}
where $\delta_{\text{defender}} = 0.25$ provides an adversarial veto offset. The verdict mapping follows: \textbf{SCAM-RISK} if $P_{\text{council}} \ge 0.60$, \textbf{LOW-RISK} if $P_{\text{council}} < 0.40$, and \textbf{UNKNOWN} (abstention) if $0.40 \le P_{\text{council}} < 0.60$.
