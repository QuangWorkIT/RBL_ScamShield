\section{Methodology}
\label{sec:method}

This section describes the benchmark dataset curation protocol, mathematical formulation of the cost-sensitive objective function, on-device ONNX edge quantization, the two-tier hybrid routing framework, and the paired statistical testing protocol.

\subsection{Benchmark Dataset and Frozen Test Partition}
We curated a unified corpus of $2,664$ genuine Vietnamese telecommunications messages by merging verified public repositories, community reports from ChongLuaDao, and national cybersecurity warning feeds (\texttt{data/raw/vietnamese\_sms\_merged\_all.csv}). The corpus contains $1,918$ benign messages ($72.0\%$) and $746$ confirmed scam instances ($28.0\%$).

To establish an uncompromised evaluation standard, we applied a stratified split with a fixed random seed of 42:
\begin{itemize}
    \item \textbf{Training and Internal Validation Partition ($90\%$):} $2,397$ messages utilized for hyperparameter optimization, loss weighting search, and model convergence.
    \item \textbf{Frozen Test Partition ($10\%$):} Exactly \textbf{$N = 267$ messages} ($192$ Ham, $75$ Scam).
\end{itemize}
The $N=267$ Frozen Test Set was not used during fine-tuning, threshold selection, or pipeline development. It was kept separate until the final evaluation.

\subsection{Model Architecture and ONNX Edge Quantization}
ViSoBERT (\texttt{uitnlp/visobert})~\cite{nguyen2023visobert} was selected as our primary on-device backbone encoder. ViSoBERT employs an XLM-RoBERTa architecture comprising 12 transformer encoder layers, 768 hidden dimensions, 12 attention heads, and approximately 97M parameters paired with a custom vocabulary of 15,000 SentencePiece tokens. Pre-trained on a curated corpus of Vietnamese social network communications, ViSoBERT captures domain-specific contextual representations for emerging internet slang, teencode, emojis, and non-diacritic text.

To evaluate real-time mobile deployability without external server dependencies, fine-tuned checkpoints were exported to the Open Neural Network Exchange (ONNX) format utilizing \texttt{opset\_version=18}. Dynamic axes were configured for variable batch size and sequence length dimensions. The resulting serialized model file (\texttt{visobert\_tier1.onnx}) occupies $390\text{ MB}$, yielding a mean inference latency of approximately $15.8\text{ ms}$ per message on standard consumer CPU threads.

\subsection{Cost-Sensitive Loss Formulation ($\mathcal{L}_{\text{WBCE}}$)}
In telecommunications security, binary classification error outcomes impose deeply asymmetric real-world consequences. Misclassifying a benign notification as scam (False Positive) incurs mild user annoyance, whereas failing to intercept an active smishing vector (False Negative) exposes victims to credential theft and financial extortion. Standard Binary Cross-Entropy (BCE) treats both error outcomes symmetrically, optimizing overall sample accuracy at the expense of positive class sensitivity.

To impose an explicit inductive bias favoring scam recall, we formulate the \textbf{Cost-Sensitive Weighted Binary Cross-Entropy Loss ($\mathcal{L}_{\text{WBCE}}$)}:
\begin{equation}
\label{eq:wbce}
\mathcal{L}_{\text{WBCE}} = -\frac{1}{N} \sum_{i=1}^{N} \left[ \alpha \cdot y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]
\end{equation}
where $y_i \in \{0, 1\}$ represents the ground-truth binary label ($0 = \text{Ham}$, $1 = \text{Scam}$), $\hat{y}_i \in [0, 1]$ denotes the predicted sigmoid probability, and $\alpha > 1$ represents the cost penalty scalar assigned to False Negatives. Differentiating Eq.~(\ref{eq:wbce}) with respect to model logits $z_i$ reveals the asymmetric gradient magnitude:
\begin{equation}
\label{eq:wbce_gradient}
\frac{\partial \mathcal{L}_{\text{WBCE}}}{\partial z_i} = \begin{cases} \alpha (\hat{y}_i - 1), & \text{if } y_i = 1 \text{ (False Negative penalty)} \\ \hat{y}_i, & \text{if } y_i = 0 \text{ (False Positive penalty)} \end{cases}
\end{equation}
In our experiments, we set $\alpha = 5.0$, exerting a 5-fold steeper gradient update whenever a true scam message is misclassified, effectively driving backpropagation to prioritize high Scam Recall. Models were fine-tuned using the AdamW optimizer with an initial learning rate of $2\times 10^{-5}$, linear warmup ratio of $0.1$, weight decay of $0.01$, and batch size of 16 across 4 epochs with FP16 mixed-precision.

\subsection{Two-Tier Routing Framework}
To resolve the operational trade-off between edge efficiency and deep semantic reasoning over ambiguous messages, ScamShield-VN implements a two-tier hybrid architecture governed by a confidence threshold $\tau = 0.90$:
\begin{equation}
\label{eq:routing}
\text{Verdict}(x) = \begin{cases} \text{Tier 1 Edge Decision}, & \text{if } \max(P(\hat{y}=1|x), 1 - P(\hat{y}=1|x)) \ge \tau \\ \text{Tier 2 Council Escalation}, & \text{if } \max(P(\hat{y}=1|x), 1 - P(\hat{y}=1|x)) < \tau \end{cases}
\end{equation}
\begin{enumerate}
    \item \textbf{Tier 1 (Edge Screener):} Incoming messages are processed on-device via quantized ViSoBERT. High-confidence predictions ($P \ge 0.90$) receive instantaneous verdicts ($< 15.8\text{ ms}$), absorbing approximately $80\text{--}85\%$ of daily message volume locally with zero cloud API costs.
    \item \textbf{Tier 2 (Forensic Council Escalation):} Ambiguous messages ($P < 0.90$) are escalated to a 5-Agent Multi-LLM Forensic Council comprising: (1) Forensic Lead, (2) Psycholinguistic Analyst, (3) Cyber Threat Intelligence Agent, (4) Financial Fraud Specialist, and (5) Public Defender / Devil's Advocate (tasked with actively identifying legitimate brand markers to suppress false alarms).
\end{enumerate}

\subsection{Evaluation Metrics and Statistical Testing Protocol}
Model performance is evaluated on the isolated $N=267$ Frozen Test Set using four primary metrics: Scam Recall ($TP / [TP + FN]$), Precision ($TP / [TP + FP]$), Macro F1-Score, and False Positive Rate ($FPR = FP / [FP + TN]$).

To rigorously establish statistical significance across paired binary classifiers on the identical test partition, we perform two-tailed \textbf{McNemar's tests} with continuity correction ($\alpha = 0.05$):
\begin{equation}
\label{eq:mcnemar}
\chi^2_{\text{cont}} = \frac{(|b - c| - 1)^2}{b + c}
\end{equation}
where $b$ represents the number of test samples correctly classified exclusively by ViSoBERT, and $c$ denotes instances correctly classified exclusively by the comparative baseline model. We evaluate the null hypothesis $H_0$ (no performance difference, $p \ge 0.05$) against the alternative hypothesis $H_1$ ($p < 0.05$). All neural models were evaluated across $K=5$ independent deterministic random seeds ($\text{SEEDS} = [42, 100, 123, 999, 2026]$).
